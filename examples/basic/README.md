# Basic Agent Example

This is the **simplest possible usage** of Agent Observatory.

It demonstrates:

- inline execution mode
- a single agent session
- basic span usage

---

## What This Example Shows

- how to create an `Observatory`
- how to start a session
- how spans work
- automatic flush on session exit

---

## Running

```bash
uv run simple_agent.py
````

---

## Key Takeaway

Use **inline mode** when:

* running scripts
* writing tests
* experimenting locally
